# shared — Muse と Claude の共有場所

ユーザーが伝言を運ばなくて済むようにするための場所です。

## 使い方
- 作業を始める前に `notes.md` を読む。
- 決定したこと、変更したこと、相手への依頼、相手が知っておくべき気づきは `notes.md` に追記する。
- 追記の形は「日付 / 誰から / 件名 / 内容 / 状態（未対応・対応済み）」。
- 価格データの受け渡しは `muse-inbox/`（Muse → Claude）。ここは連絡と申し送り専用。
- アプリ本体・データの変更は従来どおり Claude 側の作業。Muse は muse-inbox と shared 以外に触らない。
- ユーザーから直接話が来た場合も、決まったことはここに残す（相手が後から追えるように）。
