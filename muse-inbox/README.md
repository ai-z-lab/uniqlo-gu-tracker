# muse-inbox

Muse(チラシ・公式ページの巡回担当)が読み取り結果を置く場所です。ダッシュボードの「感謝祭 先行」など、始まる前の価格表示に使われます。

- 置くファイルはブランドごとに1つ: `uniqlo.json` / `gu.json`。新しい情報は上書きします(過去分はgit履歴に残ります)。
- ここ以外(`docs/`、`scripts/` など)は触りません。チラシのPDF・画像は置きません(リポジトリは公開のため)。価格などのテキストだけ。
- ダッシュボードは、このファイルの内容を `docs/preview.json` の同じブランドの商品に重ねて表示します(同じ性別・同じ商品名なら、こちらが優先)。

## 形式

```json
{
  "brand": "uniqlo",
  "source": "出典(チラシ名など)",
  "checked": "2026-11-19",
  "period": "11/20(金)〜11/26(木)",
  "until": "2026-11-26",
  "note": "画面に出す説明文(任意)",
  "items": [
    { "name": "商品名", "price": 2990, "url": "https://…", "gender": "men", "normal": 3990 }
  ]
}
```

- `price` と `name` は必須。`url` はなければ商品名の検索URLを入れる。
- `gender`(`men` / `women`)を省くと、男女どちらの表示にも出ます。
- `tags`(任意)は、対象に条件がある商品に付ける短い文字の配列。例: `["一部の色のみ", "一部サイズのみ", "オンライン限定"]`。カードに目立つ印で出ます。チラシ・公式ページに「一部」「オンライン限定」などの注記があるときだけ、その言葉のまま入れます。
- `normal`(通常価格)は分かるときだけ。なければ価格のみ表示します。
- `until` を過ぎると表示は自動で消えます。
